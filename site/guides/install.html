Guides

Install

You build Aristotle on a Linux computer and copy it to the Kindle over the USB cable. It runs on the Paperwhite 4 (2018) on firmware 5.13.x.

This can brick your Kindle. Changing a Kindle's software can leave it unusable, and no recovery method has been verified for the Paperwhite 4, which is secure-boot locked. Try it only on a device you can afford to lose.

Before you start

The Kindle needs:

  • a jailbreak;
  • KUAL, the launcher Aristotle's menu entries appear in;
  • MRPI, to install packages;
  • KOReader, for its SSH server.

Follow kindlemodding.org for all four.

Aristotle contains no jailbreak, exploit or DRM-removal code. It runs only on a Kindle you have already jailbroken with the community's tools, and it opens DRM-free books only. It uses the e-ink waveforms and firmware already on your device; it never ships, copies off or uploads them.

The Paperwhite 4 (2018, PQ94WIF) on firmware 5.13.x is the only tested device. On anything else the install scripts refuse to run; developers can override that with ARISTOTLE_FORCE=1.

The stock system stays installed underneath. Installing the device agent writes one file to the root filesystem (/etc/upstart/aristotle-agent.conf); everything else lives in the user storage and in /var/local.

Build

You need Rust through rustup with the armv7-unknown-linux-musleabihf target, and curl, tar, xz, openssl, xxd, make, cmake and a C compiler. The first script fetches a pinned Zig and builds Plato's C libraries once.

git clone --recurse-submodules https://github.com/piotrkowski/aristotle
cd aristotle
PLATO_LIBS_ONLY=1 tools/build-plato.sh
tools/build-render.sh device

The app bundle lands in $ARISTOTLE_CACHE/render/aristotle-app-device.tar.gz.

Copy it over

Create the key the device will accept, set up the USB network on the computer (NetworkManager), then plug in the Kindle as a USB drive and install:

. devloop/env.sh        # sets ARISTOTLE_CACHE, the cache directory
mkdir -p "$ARISTOTLE_CACHE/ssh"
ssh-keygen -t ed25519 -f "$ARISTOTLE_CACHE/ssh/kindle_ed25519"
devloop/host/setup-host-net.sh
devloop/host/install-extensions.sh

Set KINDLE_MOUNT if the Kindle is not mounted at /run/media/$USER/Kindle. The script puts the app in aristotle/ on the Kindle with its licences and SOURCE.txt, adds two KUAL extensions, and ejects the Kindle.

Start the agent

On the Kindle, open KUAL › Aristotle › Install agent. From then on the Kindle is reachable over SSH whenever the cable is in:

ssh -F devloop/host/ssh_config kindle

KUAL › Aristotle › Start USB network once does the same until the next reboot, without installing the agent.

Run

ssh -F devloop/host/ssh_config kindle sh /mnt/us/aristotle/run-aristotle.sh

Aristotle stops the stock interface while it runs. To quit, hold the "Library" title for a second. The stock interface comes back after its boot splash, which takes 30 to 60 seconds. A reboot also brings it back.

Uninstall

  1. On the Kindle: KUAL › Aristotle › Remove agent.
  2. Delete aristotle/, .aristotle/ (the index, page cache and snapshots) and extensions/aristotle-* from the Kindle's storage.

Removing the agent takes away everything it put on the device, including its SSH key. Your books, My Clippings.txt and the exported notes stay.

If you cannot reach the Kindle over SSH, connect it as a USB drive, create an empty file named aristotle-disable at its root, and restart it. The agent then does not start, and the stock system takes over.
