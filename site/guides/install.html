Guides

Install

You build Aristotle on a Linux computer and copy it to the Kindle over the USB cable.

This can brick your Kindle. No recovery method has been verified for the Paperwhite 4, which is secure-boot locked. Try Aristotle only on a device you can afford to lose.

Before you start

The Kindle needs a jailbreak and three packages. KUAL is the launcher that holds Aristotle's menu, MRPI installs packages, and KOReader provides the SSH server. kindlemodding.org explains how to install them.

Aristotle contains no jailbreak, exploit or DRM-removal code, and it opens only DRM-free books. It uses the e-ink waveforms and firmware already on the Kindle. Aristotle does not include them, and they never leave the device.

The only tested device is the Paperwhite 4 (2018, PQ94WIF) on firmware 5.13.x. On any other device, the scripts that change the system refuse to run. Developers can override this with ARISTOTLE_FORCE=1.

The stock system stays installed. The agent writes one file to the root filesystem, /etc/upstart/aristotle-agent.conf. Everything else goes to the user storage and /var/local.

Build

You need Rust through rustup with the armv7-unknown-linux-musleabihf target. You also need curl, tar, xz, openssl, xxd, make, cmake, bash and a C compiler. The first script, needed once, downloads a pinned Zig and builds Plato's C libraries.

git clone --recurse-submodules https://github.com/piotrkowski/aristotle
cd aristotle
PLATO_LIBS_ONLY=1 tools/build-plato.sh
tools/build-render.sh device

The app bundle is written to $ARISTOTLE_CACHE/render/aristotle-app-device.tar.gz.

Copy it over

Create the SSH key the Kindle will accept and add a NetworkManager profile for the USB network. Then connect the Kindle as a USB drive and install.

. devloop/env.sh        # sets ARISTOTLE_CACHE, the cache directory
mkdir -p "$ARISTOTLE_CACHE/ssh"
ssh-keygen -t ed25519 -f "$ARISTOTLE_CACHE/ssh/kindle_ed25519"
devloop/host/setup-host-net.sh
devloop/host/install-extensions.sh

If the Kindle is not mounted at /run/media/$USER/Kindle, set KINDLE_MOUNT. The script copies the app to aristotle/ on the Kindle with its licences and SOURCE.txt, adds two KUAL extensions and ejects the Kindle.

Start the agent

On the Kindle, open KUAL › Aristotle › Install agent. After that you can reach the Kindle over SSH whenever the cable is connected:

ssh -F devloop/host/ssh_config kindle

For SSH without installing the agent, use KUAL › Aristotle › Start USB network once. It lasts until the next reboot.

Run

ssh -F devloop/host/ssh_config kindle sh /mnt/us/aristotle/run-aristotle.sh

Aristotle stops the stock interface while it runs. To quit, hold the "Library" title for a second. The stock interface returns after its boot splash, in 30 to 60 seconds. A reboot also brings it back.

Uninstall

  1. On the Kindle, open KUAL › Aristotle › Remove agent completely. This removes everything the agent put on the device, its SSH key included. The agent's log is saved to the Kindle's storage as aristotle-agent.log.
  2. Delete aristotle/, .aristotle/ (the index, page cache and snapshots) and extensions/aristotle-* from the Kindle's storage.

Your books, My Clippings.txt and the exported notes stay.

If you cannot reach the Kindle over SSH, open KUAL › Aristotle › USB drive mode for 10 minutes and connect the Kindle to a computer. Create an empty file named aristotle-disable at the root of the drive, then restart the Kindle. The agent will not start, and the Kindle runs the stock system.
