Guides

Add books

The library shows the Kindle's documents/ folder. You add books over the USB cable.

What it reads

EPUB, DRM-free MOBI, PDF and TXT. Kindle dictionaries and the stock .sdr folders are hidden from the library.

As a USB drive

  1. In Aristotle, tap the gear in the library and set USB port to USB drive. The Kindle shows up on the computer for 10 minutes.
  2. Copy books into documents/, in subfolders if you like.
  3. Eject the drive on the computer.

When Aristotle is not running, the stock drive mode works too. The Kindle cannot write to its storage while the computer has it.

Over SSH

With the agent installed and the cable connected:

scp -F devloop/host/ssh_config book.epub kindle:/mnt/us/documents/
scp -F devloop/host/ssh_config -r Platon kindle:/mnt/us/documents/

Aristotle scans documents/ when it starts, so new books appear after a restart. The saved index shows at once, and changes are added after. An unchanged library costs one stat per file.

Folders, series and progress

The library lists subfolders first, then loose books. The back arrow goes up one level. Books whose metadata name a series get a shelf for it, in series order.

Title and author come from the metadata, or from the folder and file name when there is none. Reading positions from the stock reader and KOReader are picked up, so a book opens where you left it.

More in the library documentation.
