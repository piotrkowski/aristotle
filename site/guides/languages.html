Add a language

The interface language and the languages of your books are set up separately.

The interface

The interface is in English, with a Polish translation. Settings › Language lists the built-in languages under their own names and switches at once.

Messages live in crates/aristotle-i18n/locales/<code>.json, one file per language, with en.json as the reference. They are grouped by screen, one level deep ("library": {"title": "Library"}), and use {name} placeholders. Plural messages list their forms ({"one": "{n} book", "other": "{n} books"}). The build checks each file against en.json and embeds it, so a broken translation fails the build and the Kindle reads no language files.

Adding a language

  1. Copy en.json to a file named after the language code, such as de.json.
  2. Translate the messages. Keep the {placeholders} and give plural messages the forms the language needs.
  3. Fill in "@locale" with the language's own name, the decimal separator, the twelve months as used in dates, the seven weekdays from Sunday, and the date pattern ({weekday}, {day}, {month}, {year}) and time pattern ({h}, {hh}, {mm}).
  4. If the language's plurals are not "one for 1, other otherwise", add a rule to crates/aristotle-i18n/src/plural.rs (Rule::for_language, categories, select). Test it with 0, 1, 2, 5, 12, 14, 21, 22, 25, 112 and 122. Polish, for example, has one, few and many: 1 książka, 2 książki, 5 książek.
  5. Run cargo test -p aristotle-i18n. It lists missing keys and wrong placeholders. A partial translation can set "complete": false in "@locale". Its missing messages then fall back to English, with a build warning.
  6. Check the screens with aristotle-ui-preview --lang <code> and the reader with aristotle --preview ... --lang <code>. Chips and segment labels may need shorter wording.

The language then shows up in the settings. More in Adding a language in the UI framework notes.

Your books

Books are hyphenated in their own language, whatever the interface language. The default build has patterns for Polish, English (US and UK), Ancient Greek and Latin. Add others at build time in HYPH_LANGS. German is de-1996, French is fr.

HYPH_LANGS="pl en-us en-gb grc la de-1996 fr" tools/build-render.sh device

A new language also needs the SHA-256 of its hyph-utf8 licence notice in tools/build-render.sh, which pins its downloads. Without it the script stops and names the language. The default keeps to five languages because Plato loads all bundled patterns the first time it hyphenates.

The patterns come from Plato's release, which takes them from hyph-utf8. A book's language comes from its metadata. If an EPUB declares several, Aristotle picks the one its text is written in.

The default build trims the fonts to Latin and Greek, polytonic included. FONT_SUBSET=none keeps all glyphs, Cyrillic among them.
