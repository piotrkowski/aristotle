Add a language

Two different things: the language of the interface, and the languages of your books.

The interface

The interface is in Polish for now. English and other languages come with translation catalogs, which are being built. This guide will have the steps once they land; until then, Adding a language in the UI framework notes is the place to watch.

The plan, from the architecture notes:

  • One catalog per language, as Rust code: a missing or misspelt message fails to compile.
  • Plural forms per language: English has one and other; Polish has one, few and many (2 książki, 5 książek).
  • The catalog also holds month and weekday names, the decimal separator, and how dates, sizes and durations are written.
  • The language is a setting: Automatic, English, Polski.

Your books

Books are hyphenated in their own language, whatever the interface language. The default build ships patterns for Polish, English (US and UK), Ancient Greek and Latin. Others can be added at build time, by name in HYPH_LANGS (German is de-1996, French fr):

HYPH_LANGS="pl en-us en-gb grc la de-1996 fr" tools/build-render.sh device

The script pins every file it downloads, so a new language also needs the SHA-256 of its hyph-utf8 licence notice in tools/build-render.sh; it stops with a message naming the language until then. Plato loads every pattern file in the bundle the first time it hyphenates, which is why the default ships only five.

The patterns come from Plato's release, which collects them from hyph-utf8. A book's language comes from its metadata; when an EPUB declares several, Aristotle picks the one its text is actually written in.

The default build also cuts its fonts to Latin and Greek, polytonic included. FONT_SUBSET=none keeps everything the fonts have, Cyrillic among it.
