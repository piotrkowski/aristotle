Add dictionaries

Hold a word while reading and its definition pops up, from dictionaries on the Kindle. Nothing goes over the network.

Which files

Aristotle reads StarDict dictionaries: an .ifo file with its .idx, .dict or .dict.dz, and optionally .syn for inflected forms. The Wiktionary exports from wiktionary_stardict work well: HTML entries, and inflected forms as synonyms (1.4 million for Polish, 1.8 million for Ancient Greek).

Name the files after the language pair, source first: grc-pl.ifo is Ancient Greek to Polish, la-en.ifo Latin to English. Aristotle takes the languages from the name.

Where they go

Put each dictionary in its own folder, one level deep, under either of:

/mnt/us/dictionaries/grc-pl/grc-pl.ifo
/mnt/us/koreader/data/dict/grc-pl/grc-pl.ifo

On the USB drive these are dictionaries/ and koreader/data/dict/. The second is where KOReader keeps its dictionaries, so those work in Aristotle too.

Indexing

Each dictionary gets an index the first time Aristotle sees it. It folds every headword and form to plain letters, so lookups ignore accents, Greek breathings and missing Polish diacritics: ψυχὴ, ΨΥΧΗ and ψυχη all find ψυχή.

  • Missing indexes are built at start, in the background, at idle priority, so reading is not slowed down. They are stored in .aristotle/dict-index/.
  • Large dictionaries take a while on the device the first time. The Polish Wiktionary's index is 21 MB; it took 846 ms to build on a PC, and the Kindle is many times slower.
  • To skip the wait, build the indexes on the computer and copy them over:
aristotle --index-dicts --dict DICTIONARIES --library OUT
scp -F devloop/host/ssh_config -r OUT/dict-index kindle:/mnt/us/.aristotle/

Which dictionary answers

  • Greek script means Ancient Greek; otherwise the book's language decides.
  • Dictionaries into the interface language come first (grc-en before grc-pl in English, grc-pl first in Polish), then the others for that language. For Latin-script words, the other Latin-script dictionaries follow, since Latin phrases turn up in Polish books.
  • The popup has a tab per dictionary. The one you pick is remembered per language.
  • Inflected forms find their dictionary form: through the dictionary's own forms, through another dictionary of the same language, or by suffix rules for Polish, Greek and Latin, marked as a guess.

A selection of several words can be glossed word by word with Translate, from the same dictionaries.
