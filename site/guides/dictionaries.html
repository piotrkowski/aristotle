Add dictionaries

Hold a word while reading to see its definition. Lookups use dictionaries stored on the Kindle.

Which files

A StarDict dictionary is an .ifo file with an .idx, a .dict or .dict.dz, and an optional .syn file of inflected forms. The Wiktionary exports from wiktionary_stardict work well. They have HTML entries and list inflected forms as synonyms, 1.4 million for Polish and 1.8 million for Ancient Greek.

Name the files after the language pair, source first. grc-pl.ifo is Ancient Greek to Polish, la-en.ifo is Latin to English.

Where they go

Put each dictionary in its own folder, directly under one of these two directories:

/mnt/us/dictionaries/grc-pl/grc-pl.ifo
/mnt/us/koreader/data/dict/grc-pl/grc-pl.ifo

On the USB drive these are dictionaries/ and koreader/data/dict/. The second is KOReader's, so its dictionaries work too.

Indexing

Aristotle indexes each dictionary the first time it sees it. The index reduces words to plain letters, so lookups ignore accents, Greek breathings and missing Polish diacritics. ψυχὴ, ΨΥΧΗ and ψυχη all find ψυχή.

Missing indexes are built in the background at idle priority and stored in .aristotle/dict-index/. The Polish Wiktionary index is 21 MB. It took 846 ms to build on a PC and 22.9 s on the Kindle. To skip the wait, build the indexes on the computer and copy them over:

aristotle --index-dicts --dict DICTIONARIES --library OUT
scp -F tools/host/ssh_config -r OUT/dict-index kindle:/mnt/us/.aristotle/

Which dictionary answers

Words in Greek script are looked up as Ancient Greek, other words in the book's language. Dictionaries into the interface language come first, so grc-en precedes grc-pl in English and follows it in Polish. Latin-script words also try the other Latin-script dictionaries, because Latin phrases turn up in Polish books.

The popup has a tab for each dictionary and remembers your choice per language. Inflected forms are found through the dictionary's own forms, another dictionary of the same language, or suffix rules for Polish, Greek and Latin. Suffix-rule matches are marked as guesses.
