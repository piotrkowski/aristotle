# The Wi-Fi screen and the keyboard, with the updates each action must cause
# (docs/ui-framework.md, "Transitions" and "Text input"). Run it with the app
# started with --wifi-read-only, in English, on the library home, Wi-Fi off:
#   /var/tmp/aristotle-observe run /var/tmp/aristotle-wifi.txt
# --wifi-read-only makes connecting and forgetting fail before any LIPC call,
# so tapping a network of someone else's is harmless; the scenario still
# never submits a valid password. It switches Wi-Fi on, scans and switches
# it off again. Networks come from the real scan, so the row tapped below
# may be an open one (then the screen says the connection failed) instead of
# a secured one (then the keyboard opens): check the snaps.
# "A2" is the touch-down acknowledgement; "quiet" one partial DU/GL16 update;
# "flash" one full mode-8 update of the whole screen.

wait 2000
snap uikb-start

# --- Settings, page 2, the Wi-Fi row (A2 + flash) ---
label settings-open
tap 948 118
wait 3000
label settings-page-2
tap 948 1377
wait 2500
snap uikb-settings-2
label wifi-open
tap 536 1088
wait 3000
snap uikb-wifi

# --- Wi-Fi on: A2 + quiet ("Turning on..."), then quiet updates as the
# radio comes up and the scan ends (about 6 s) ---
label wifi-on
tap 536 240
wait 9000
snap uikb-wifi-on
label scan-again
tap 880 574
wait 4000
snap uikb-wifi-scanned

# --- A network: the fourth row (A2 + flash to the keyboard if secured) ---
label network-4
tap 536 1057
wait 3000
snap uikb-password
