# Opening books in the Aristotle reader through page snapshots, and using a
# book before its layout is done. Run with the app up
# (device/app/run-aristotle.sh in another shell), its library on screen,
# and at least two books. Best with a long MOBI novel without chapter breaks
# as the book to continue: it is one huge chapter, so the layout takes about 2 s on the device and every
# step below lands while the book is still opening.
#
# Coordinates follow the library and menu layouts of 2026-10-17 (in any UI
# language): the "Continue reading" card at the top, the first list row
# below the filters, the menu's "Library" button top left. Check each snap.
#
# What to verify, in the snaps and in /var/tmp/aristotle.log:
# - every open: the card inverts on touch-down, then exactly one flash to
#   the book page; "open: ... snapshot submitted after N ms" (except the
#   very first open, which writes the snapshot), then "book ready ... snapshot
#   Same" and no "corrected page" update;
# - the turn during the open: "turn Forward: ... a snapshot page";
# - the menu during the open: it opens at once with the chapter and page
#   labels;
# - back during the open: "back to the library ... before the book was
#   ready", one flash to a complete library;
# - the other book opens normally, unslowed by the abandoned one (if the
#   first list row is the same book, pick another row);
# - reopening the card (now the other book) shows its snapshot again.
