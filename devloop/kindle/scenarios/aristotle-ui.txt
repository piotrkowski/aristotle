# Every screen and control of the Aristotle app, with the updates each
# action must cause (docs/ui-framework.md, "Transitions"). Run it with the
# app in front, in English (the default language), on the library home
# ("Library", view Books, shelf All, covers off, night off, a book opened
# before so "Continue reading" is shown):
#   /var/tmp/aristotle-observe run /var/tmp/aristotle-ui.txt
# Coordinates come from `aristotle-ui-preview` (targets.txt), which lays out
# the same screens; chips and tabs move with the language, so for another
# one take them from `aristotle-ui-preview --lang CODE`. "A2" below is the touch-down acknowledgement; "quiet" is
# one partial DU/GL16 (GLKW16 at night) update of the changed region;
# "flash" is one full update of the whole screen in mode 8; "turn" one full
# update of the whole screen in mode 9.
#
# Not driven here on purpose: "USB drive" in the settings (it drops the USB
# network and SSH for 10 minutes; try it by hand), the language chips, and
# quitting (hold the "Library" title for a second).
