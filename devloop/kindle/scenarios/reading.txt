# the highlights list, go to 50 %.

# Coordinates come from `aristotle --preview` on the same book with the
# default typography (10 pt, normal spacing and margins: reader.json absent
# or at its defaults); regenerate this file with it after layout changes
# (docs/reader.md, "Reading interactions").
#
# Setup, once:
#   devloop/host/make-reading-test-epub.py proba-czytania.epub
#   copy it to /mnt/us/documents/Aristotle/, and build the dictionary
#   indexes on the host (aristotle --index-dicts) into
#   /mnt/us/.aristotle/dict-index/ (else the device builds them at start;
#   lookups say "Słownik jest indeksowany" until then).
# Run, the app in front with the book open. --test-clippings keeps the
# scenario's highlight out of the user's My Clippings.txt (note-taking
# tools may import it on every plug-in); check it is byte-identical:
#   ssh kindle md5sum "/mnt/us/documents/My Clippings.txt"
#   ssh kindle sh /mnt/us/aristotle/run-aristotle.sh --open "Próba czytania" \
#       --test-clippings /var/tmp/reading-test/My\ Clippings.txt
#   /var/tmp/aristotle-observe run /var/tmp/reading.txt
#   ssh kindle md5sum "/mnt/us/documents/My Clippings.txt"   # unchanged
#   ssh kindle cat "/var/tmp/reading-test/My Clippings.txt"  # the test highlight
